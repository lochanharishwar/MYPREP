# Robot section illustrations — 9 October 2026

Nineteen original section mascots were generated with the built-in image-generation tool, using the user's final colorful cartoon robot badge sheet as a style reference. The earlier watercolor and photorealistic concepts were discarded and are not shipped.

Final assets are in `public/illustrations/robots/`. Each is a transparent 384px WebP optimized from its generated original. Total delivery size is approximately 595 KB. `SectionHeading` and `SectionMascot` place them beside information headings across all six pages, including the eight Brand DNA strategy divisions. They are decorative, have empty alternative text, and do not substitute for observed logos, page screenshots, brand evidence or metrics. No animation is required; lazy loading and explicit dimensions avoid layout shifts.

## Prompt set

Common prompt: Use the supplied badge sheet as a style reference only; create one original robot mascot badge. Lively flat 2D cartoon editorial illustration with bold geometric silhouettes, chunky friendly proportions, distinct personalities, cream and saturated accent panels, dark navy screen faces, expressive glowing eyes, crisp edges, subtle grain and cel shading. Waist-up character with arms and a relevant prop, centered on a muted slate-blue circular backing disc with clear margins. Transparent outside the circle. Legible at 140px. No text, logos, watermark or copied character. No photorealistic metal rendering or human anime character.
