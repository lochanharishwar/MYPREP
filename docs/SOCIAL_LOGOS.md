# Social platform artwork

Retrieved 13 October 2026 from the platforms' official resources. The connection hub shared by the scheduler and workspace settings uses local assets under `public/platforms/`; it does not depend on remote image requests or font glyphs. Colors and aspect ratios are preserved. Raster files are proportionally resized to a maximum of 128px for crisp small UI marks. Adjacent text provides each platform's accessible name.
